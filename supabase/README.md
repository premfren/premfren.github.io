# ซิงก์สองเครื่องด้วย Supabase

ตั้งค่าครั้งเดียว: ใน Supabase ไปที่ **SQL Editor › New query** วางทั้งไฟล์ `supabase/schema.sql` แล้วกด **Run**

ใช้งาน: เปิดแอปบนมือถือทั้งสองเครื่อง ใส่รหัสผ่านเดียวกัน ติ๊ก "จำรหัสผ่านในเครื่องนี้" แค่นี้ก็ซิงก์อัตโนมัติ ไม่ต้องส่งลิงก์

- แก้ที่เครื่องไหนก็ขึ้นอีกเครื่อง (เช็คทุก 15 วิ และทุกครั้งที่เปิดแอป) รวมถึงการเพิ่ม/ลบทริป
- แก้พร้อมกันหรือแก้ตอนออฟไลน์ทั้งสองเครื่องก็ไม่หาย แอปรวมการแก้ไขทีละรายการ ถ้าแก้ช่องเดียวกันพร้อมกัน เครื่องที่ซิงก์ทีหลังชนะ
- QR ตม. และข้อมูลพาสปอร์ตไม่ถูกส่งขึ้น Supabase อยู่ในเครื่องเท่านั้น
- รหัสผ่านไม่ได้อยู่ใน repo มีแค่ค่าตรวจสอบ (PBKDF2) ใน `config.js` ส่วนรหัสลับที่ใช้ซิงก์คำนวณจากรหัสผ่านในเครื่อง
- ล็อกแอป/ลืมรหัสที่จำไว้: หน้าแรก › ปุ่ม ⋯ › ล็อกแอป
- เปลี่ยนรหัสผ่าน: ดูคำสั่งใน `config.js` (เปลี่ยนแล้วข้อมูลบนเซิร์ฟเวอร์จะเริ่มชุดใหม่ ข้อมูลในเครื่องยังอยู่และจะถูกอัปโหลดใหม่)

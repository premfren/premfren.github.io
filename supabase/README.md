# ตั้งค่าซิงก์ด้วย Supabase (ทำครั้งเดียว ~5 นาที)

1. สมัคร/เข้า https://supabase.com › **New project** (Region แนะนำ Singapore) ตั้งรหัส DB อะไรก็ได้
2. เมนู **SQL Editor › New query** › วางทั้งไฟล์ `supabase/schema.sql` › **Run**
3. เมนู **Project Settings › API Keys** คัดลอก
   - **Project URL** (เช่น `https://abcdefgh.supabase.co`)
   - **Publishable key** (`sb_publishable_…`) หรือ legacy **anon** key
4. ใส่ทั้งสองค่าใน `config.js` แล้ว push ขึ้น GitHub (คีย์นี้เปิดเผยได้ ฐานข้อมูลตอบเฉพาะคนที่มีลิงก์ลับของทริป)
5. เครื่องแรก: เปิดทริป › ปุ่มซิงก์ › **เปิดซิงก์ แล้วส่งลิงก์ให้อีกคน**
6. เครื่องที่สอง: เปิดลิงก์ที่ได้รับ (หรือปุ่มซิงก์ › เข้าร่วมด้วยลิงก์)

หลังจากนี้ แก้ไขเครื่องไหนก็ขึ้นอีกเครื่องภายในไม่กี่วินาทีเมื่อเปิดแอปอยู่ (เช็คทุก 15 วิ และทุกครั้งที่เปิดแอป)
แก้พร้อมกันหรือแก้ตอนออฟไลน์ทั้งสองเครื่องก็ไม่หาย แอปรวมการแก้ไขทีละรายการ ถ้าแก้ช่องเดียวกันพร้อมกัน เครื่องที่ซิงก์ทีหลังชนะ
QR ตม. และข้อมูลพาสปอร์ตไม่ถูกส่งขึ้น Supabase อยู่ในเครื่องเท่านั้น
